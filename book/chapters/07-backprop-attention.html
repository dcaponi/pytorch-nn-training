Where Q, K and V Come From

Each explanation of attention derives the forward pass, and almost none derive the backward pass. Thus the question that readers really have stays without an answer. The three projections make queries, keys and values from an embedding. But nothing says where the projections came from. This chapter answers that question in the only honest way: it differentiates the full calculation and follows the result back to each matrix.

The short answer, before the long one

$W^Q$, $W^K$ and $W^V$ are ordinary parameters. They start at random values. The same optimizer step as each other weight in the model updates them. They train together with everything else, also the feed-forward head, against one scalar loss. There is no separate objective for attention. There is no phase where the projections train before the rest of the network. And nothing in training tells a query what it should look for.

Key concept There is no attention loss. The only quantity that the model ever minimizes is the loss of the end task: next-token cross-entropy, translation cross-entropy or a classification objective. $W^Q$ learns only because a change to it changes that number. Each head that you can interpret in a paper is a by-product. Nobody asked the model for a coreference head. A coreference head is what minimized perplexity.

That answer is correct, but it does not satisfy. It does not explain how a signal from the output turns into a sensible change to a matrix. That signal is thousands of dimensions and a dozen layers away. The matrix decides what position 7 looks at. That is a question about the backward pass. The rest of this chapter is the derivation.

One function, one scalar

Be exact about what a trained network is, because that exactness makes the rest easy. A transformer is one function:

$$L = \mathcal{L}\big(\theta;\ \text{data}\big) \in \mathbb{R}$$

Here $\theta$ contains each parameter in the model: the embeddings, all four projections in each attention block, both feed-forward layers, each LayerNorm scale and shift, and the output head. The loss is one number. Training asks for $\partial L/\partial\theta$, which is one number for each parameter, and takes a step against it. That is all. It is the same statement as the two-layer network of Chapter 01. Only the length of the chain is different.

Here is the chain for one encoder block, written out:

Example — the path from $W^Q$ to the loss
W^Q ──▶ Q ──▶ S = QKᵀ/√d_k ──▶ P = softmax(S) ──▶ O = PV │ ▼ concat heads, W^O │ ▼ residual add, LayerNorm │ ▼ feed-forward network │ ▼ (× N blocks) ──▶ head ──▶ logits │ ▼ cross-entropy L

There are nine links. The backward pass goes through that list in reverse, and each link gives one multiplication. Nothing in it is special to attention. It is the same chain rule as in all other places. But two of the links behave in ways that decide how the model trains. Those two are the softmax and the residual add. This chapter covers the softmax. Chapter 08 covers the residual add.

The backward pass of scaled dot-product attention

Use one head, and remove the batch axis. Here is the forward pass, with the shapes from Chapter 06:

$$S = \frac{QK^{\top}}{\sqrt{d_k}}, \qquad P = \operatorname{softmax_{row}}(S), \qquad O = PV$$

$Q$ and $K$ have shape (L, d_k), $V$ has shape (L, d_v), and $S$ and $P$ are square at (L, L). Suppose that the rest of the network already gave us $G = \partial L/\partial O$, with the same shape as $O$. All the results below come from the chain rule and nothing more.

Through the value multiplication. $O = PV$ is a plain matrix product, so it transposes in the usual way:

$$\frac{\partial L}{\partial V} = P^{\top}G, \qquad\qquad \frac{\partial L}{\partial P} = GV^{\top}$$

Through the softmax. This is the only interesting step. The softmax acts on each row independently. Thus, take one row: $p = \operatorname{softmax}(s)$, both of length $L$. Write $g = \partial L/\partial p$ for that row. Its Jacobian is $J = \operatorname{diag}(p) - pp^{\top}$. (The Jacobian is the matrix of all the $\partial p_i/\partial s_j$. You multiply by it to move the gradient back across the softmax.) Note that it is not diagonal. A softmax mixes each input into each output. Thus, unlike ReLU, you cannot apply it entry by entry. $J$ is symmetric, so:

$$\frac{\partial L}{\partial s} = Jg = p \odot \big(g - (p \cdot g)\big)$$

Do that for each row, and you have $\partial L/\partial S$. We call it $dS$. Note its form. First, subtract one scalar, $p \cdot g$, from each entry. Then multiply elementwise by $p$. Both halves are important. The next section is about what they do.

Through the scale and the dot products. $S = QK^\top/\sqrt{d_k}$ is again a matrix product, with a constant in front:

$$\frac{\partial L}{\partial Q} = \frac{dS\,K}{\sqrt{d_k}}, \qquad\qquad \frac{\partial L}{\partial K} = \frac{dS^{\top}Q}{\sqrt{d_k}}$$

Finally, into the parameters. $Q = XW^Q$, so:

$$\frac{\partial L}{\partial W^Q} = X^{\top}\frac{\partial L}{\partial Q}$$

$W^K$ and $W^V$ have the same form. The input $X$ collects all three contributions, because it went into all three projections:

$$\frac{\partial L}{\partial X} = \frac{\partial L}{\partial Q}W^{Q\top} + \frac{\partial L}{\partial K}W^{K\top} + \frac{\partial L}{\partial V}W^{V\top}$$

That is the complete backward pass of an attention head. It has six lines and no approximations. Each line is a transpose and a multiplication, except the softmax. If you implement those six lines, you get the same values as autograd to floating-point precision. The notebook tells you to do exactly that.

By hand — exercise 07.1

This continues exercise 06.1. It uses the same three tokens, the same $d_k = 2$ and the same matrices:

Q = K = V = [[1, 0], [0, 1], [1, 1]] From 06.1, row 1 of P is p = [0.401, 0.198, 0.401] and the output of position 1 is o₁ = [0.802, 0.599]. Suppose the loss depends only on the first component of o₁, so the gradient arriving from above is g = ∂L/∂o₁ = [1, 0].
  1. Calculate row 1 of $\partial L/\partial P$. (Each entry is $g \cdot v_j$. You ask how much each value vector contributed to the component that you care about.)
  2. Calculate the scalar $p \cdot g$ for that row.
  3. Calculate row 1 of $dS$ with $p \odot (g - (p\cdot g))$. Then add the three entries. What do you get? Why must you get that for each row of each softmax?
  4. Calculate $\partial L/\partial q_1$. Remember the $1/\sqrt{2}$.
  5. Do not calculate it. Which rows of $\partial L/\partial K$ are not zero? Which rows of $\partial L/\partial V$? Explain the difference in one sentence.
Worked solution

1. $(\partial L/\partial P)_{1j} = g \cdot v_j$ with $g = [1,0]$. Thus it selects the first component of each value vector:

v₁ = [1,0] → 1 v₂ = [0,1] → 0 v₃ = [1,1] → 1 ∂L/∂P row 1 = [1, 0, 1]

2. $p \cdot g = 0.401(1) + 0.198(0) + 0.401(1) = 0.802$. This is the output component itself. That is not a coincidence, because $o_{1,0} = \sum_j p_j v_{j,0}$.

3. Subtract 0.802 from each entry, then multiply by $p$:

[1 − 0.802, 0 − 0.802, 1 − 0.802] = [0.198, −0.802, 0.198] × p [0.401, 0.198, 0.401] = [0.0793, −0.1587, 0.0793] sum = 0.0793 − 0.1587 + 0.0793 = 0.0000

The row sums to zero, and it always will: $\sum_j p_j(g_j - p\cdot g) = p\cdot g - (p \cdot g)\sum_j p_j = 0$, because the softmax weights sum to 1. Keep this as a debug check. If you write your own attention backward and a $dS$ row does not sum to zero, the bug is in your softmax gradient and nowhere else.

4. $\partial L/\partial q_1 = \frac{1}{\sqrt 2}\sum_j dS_{1j}k_j$:

0.0793[1,0] + (−0.1587)[0,1] + 0.0793[1,1] = [0.1587, −0.0793] ÷ √2 = [0.1122, −0.0561]

When you ask autograd the same question, it returns [0.112190, -0.056095].

5. All three rows of $\partial L/\partial K$ are not zero, and all three rows of $\partial L/\partial V$ are not zero. But the reasons are different, and the next section is about that difference. Each value vector went into $o_1$ with weight $p_j$. Thus each one gets gradient $p_j g$ directly. Each key was compared with $q_1$. Thus each one gets gradient only through the softmax row. That is why those entries carry the factor $p_j(g_j - p\cdot g)$. They can vanish when the value gradients do not.

Why V learns easily and Q and K do not

Look at the two paths next to each other. The gradient that gets to $V$ is $P^\top G$. It is a matrix product, linear in the gradient that comes in, and no Jacobian of a non-linearity is in the way. Values are on the easy path. $W^V$ trains approximately as easily as any ordinary linear layer in the network.

The gradient that gets to $Q$ and $K$ must first go through $p \odot (g - (p\cdot g))$, and that expression can fail. Suppose that a row of $P$ has become confident: one weight is near 1, and the others are near 0. For the entry near 1, $p \cdot g \approx g_j$, so the bracket is near zero. Each other entry is multiplied by $p_j \approx 0$. Both terms disappear at the same time. In the limit, this is exact, not approximate. If $p$ is exactly one-hot at index $m$, then $p\cdot g = g_m$. Entry $m$ gives $1 \cdot (g_m - g_m) = 0$, and each other entry gives $0 \cdot (\cdot) = 0$. The row returns exactly zero. $W^Q$ and $W^K$ learn nothing from it, at any learning rate, for as long as it stays that way.

This is the argument for the square-root scale of Chapter 06, now stated in terms of what it protects. Division by $\sqrt{d_k}$ is not about a tidy forward pass. It keeps the attention rows soft enough that the backward pass still has a signal for them. Clear the scale in the widget and increase $d_k$. The row becomes one-hot, and the gradient that it returns disappears.

Measured — and not where you would look for it

The notebook runs this over random heads at $d_k$ from 2 to 256. The first half of the result is what you expect. With the scale, the mean entropy of the attention rows is flat in $d_k$. Without it, the entropy decreases steadily from 2.17 to 0.18 nats. The rows saturate exactly as the algebra predicts.

The second half is not what this chapter originally claimed. At $d_k = 128$, the total $\|\partial L/\partial S\|$ almost does not change: 4.53 with the scale and 3.17 without it. And $\|\partial L/\partial W^Q\|$ is larger without the scale: 283 against 38. On any plot of aggregate gradient norm, the model without the scale looks healthier.

The collapse is there, but it occurs row by row. With the scale, the gradient of the loudest row is approximately $9\times$ the gradient of the quietest row. Without the scale, the spread is twelve orders of magnitude, and 15% of the rows return less than $10^{-4}$. Those rows are dead, but the rows that stay alive are loud enough to keep the average up. This lesson also applies outside attention. A mean or a global norm cannot see a failure that affects only a subset. Plot the distribution.

The same failure, under three names When you can see this term, three pieces of training folklore become one phenomenon. Attention entropy collapse is this row becoming one-hot early and never recovering. Learning-rate warmup helps because it keeps the early updates small. Thus no head becomes sharp before the representation that it attends to is worth attention. QK-LayerNorm normalizes $Q$ and $K$ before the dot product, and it is now standard in large models. It limits the score magnitudes directly. That is the same fix as $\sqrt{d_k}$. But it also works when the weights change scale during training, not only at initialization.
Masking, for free A masked entry has $S_{ij} = -\infty$. Thus $p_{ij} = 0$, and $dS_{ij} = p_{ij}(g_{ij} - p\cdot g) = 0$ exactly. The mask needs no backward implementation at all. A masked position cannot get gradient, because the same zero that removed it from the forward average removes it from the backward sum. That is why Chapter 06 says that you must mask before the softmax. If you mask after it, $p_{ij} \neq 0$, and a future token would silently teach a past position what to look for.

Q and K are only ever a product

Here is one more structural fact. It is easy to miss, and it is useful. The scores depend on $W^Q$ and $W^K$ only through this expression:

$$S = \frac{X W^Q (W^K)^{\top} X^{\top}}{\sqrt{d_k}}$$

Thus only the product $M = W^Q(W^K)^\top$ affects the function that the model calculates. Multiply $W^Q$ by any $c \neq 0$ and $W^K$ by $1/c$, and the model is identical: the same outputs and the same loss, on each input. The parameterization is redundant. Thus the loss surface has a flat direction through each point.

Differentiate that invariance along $c$ at $c = 1$. This gives a relation that the gradients must satisfy, for any model and any data, at any point in training:

$$\Big\langle \frac{\partial L}{\partial W^Q},\, W^Q \Big\rangle = \Big\langle \frac{\partial L}{\partial W^K},\, W^K \Big\rangle$$

This has two results. First, it is a real test. If you implement attention backward yourself, this equality is true to floating-point noise, and the notebook checks it. Second, it explains a practical problem. The individual norms of $W^Q$ and $W^K$ are not useful quantities to monitor or to regularize. The optimizer can move along the flat direction without a change to anything. Weight decay on both does have an effect: it prefers the balanced point on each flat line. That is a small example of a regularizer that acts on the parameterization, not on the function.

Where the gradient is born

All the material above assumed that $G = \partial L/\partial O$ came from somewhere. In the end, it comes from one subtraction. Take one position with logits $z$, predicted distribution $\hat{y} = \operatorname{softmax}(z)$ and one-hot target $y$. The gradient of cross-entropy with respect to the logits is:

$$\frac{\partial L}{\partial z} = \hat{y} - y$$

The derivation is in Chapter 00. It is the reason to keep softmax and cross-entropy together. Separately, each one has a difficult Jacobian. Together, they become one subtraction.

What gets updated, and by what

ParameterShapeWhere its gradient arrives from
$W^V$, $W^O$(d_model, d_model)a linear path — no non-linearity's Jacobian in the way
$W^Q$, $W^K$(d_model, d_model)only through their own layer's softmax; zero if its rows saturate
FFN $W_1$, $W_2$(d_model, d_ff)through ReLU — zero for any unit its input never activates
$\gamma$, $\beta$(d_model,)summed over every token in the batch, so large and low-variance
Token embeddings(V, d_model)only the rows for tokens that appeared; the rest get exactly zero
Learned positions(L_max, d_model)only rows up to the longest sequence in the batch

The last two rows surprise people. The embedding of a rare token changes only on the few steps where the token occurs. At all other steps, nothing changes it. Thus rare-word embeddings stay near their initialization, and a large vocabulary needs more data, not only more parameters. Also, a learned positional table has never seen row 3000 if training never used a sequence that long. That row is still at its initialization, and the model gives confident nonsense there. A fixed formula has no parameters, so it cannot fail that way. Chapter 08 comes back to this trade when it introduces the two options. Note now that the choice between them first shows as a property of the backward pass.

By hand — exercise 07.2

There is no arithmetic. This exercise uses the encoder–decoder of Chapter 09. Its cross-attention takes queries from the decoder, and keys and values from $M$, the output of the encoder. If you have not read Chapter 09, come back to this exercise after it. A translation model has a 6-layer encoder and a 6-layer decoder. You calculate the loss on one target position, the third word of one sentence, and call backward(). For each item below, say whether the gradient is zero or not, and why:

  1. $W^V$ in the self-attention of decoder layer 6.
  2. $W^Q$ in the cross-attention of decoder layer 2.
  3. $W^Q$ in encoder layer 4.
  4. The embedding row for the fifth target token.
  5. The embedding row for a source word in the sentence.
  6. $\gamma$ of the final encoder LayerNorm.
Worked solution

1. Not zero. With the causal mask, position 3 attends to positions 1–3, and their value vectors go into its output.

2. Not zero. Note that it is a decoder parameter, but it is in the sub-layer that talks to the encoder. Its gradient is $H_2^\top(\partial L/\partial Q_2)$, made only from decoder hidden states.

3. Not zero. The route is long: encoder 4 → encoder 5 → encoder 6 → $M$ → the $K$ and $V$ of each decoder layer → the loss. But each link exists, so the chain rule gives something. This answers the question "how does the encoder know anything?". It knows because this path exists, and for no other reason.

4. Zero. The fifth target token is at position 5, and position 3 cannot attend to it. The causal mask gives it exactly zero weight, and a masked entry returns exactly zero gradient. It is also not the target of the position that we scored. Both routes are closed.

5. Not zero. The bidirectional attention of the encoder can see each source token. Each source token gets to the decoder through cross-attention, whichever target position you scored.

6. Not zero, and it will be one of the larger gradients in the model. $\gamma$ is one $d_{\text{model}}$-vector, and it collects a contribution from each source token, not from one position.

The answers are not the useful part. The method is. To decide whether a parameter gets gradient, do not think about what it is for. Look for a path in the graph. Then make sure that no mask or saturated non-linearity sets it to zero on the way.

In the wild

loss.backward() runs all six equations above. PyTorch records the forward operations as a graph. Then it goes through the graph in reverse, and calls the registered backward of each operation. torch.autograd.Function is the interface. The main exercise of the notebook is to write one for attention. 

loss.backward()
for name, p in model.named_parameters():
    if p.grad is None:
        print(name, "received no gradient at all")   # disconnected from the loss
    else:
        print(name, p.grad.norm().item())

For the subject of this chapter, that loop is the most useful debug tool. A None gradient means that the parameter is not on any path to the loss. For example, a head is disconnected, a tensor was rebuilt with .detach(), or a branch was never called. A gradient norm of exactly zero means that a path exists, but a mask or a saturated softmax closed it.

torch.autograd.gradcheck compares an analytic backward with finite differences in double precision. It is the correct way to trust your own Function. It hides two things that you should know. First, autograd stores the (B, H, L, L) attention matrix for the backward pass. That is the memory cost of exercise 06.2 in Chapter 06. Second, FlashAttention does not store it. It calculates $P$ again during the backward pass from $Q$ and $K$. It trades arithmetic for memory, and it calculates the same six equations both ways.

Feel for the numbersMust do

Gradients have expected magnitudes and exact invariants, and you can check both. The invariants are especially useful. When you debug your own backward pass, a quantity that must be exactly zero is the most useful thing that you can have.

Now do these on paper. Where you can, do them in your head. You can use a calculator for the logarithms. The goal is to know which number to use.

  1. A row of $P$ is exactly one-hot. What is the gradient to each score in that row? Is that approximate or exact?
  2. You write your own attention backward, and one $dS$ row sums to $0.03$. Where is the bug? Where is it certainly not?
  3. Each logged gradient norm looks healthy, but one head has clearly stopped learning. Which statistic did you not examine?
Answers

1. Exactly zero, at each entry. For the hot index, $p \cdot g = g_m$, so the bracket $(g_m - p\cdot g)$ is zero. For each other index, $p_j = 0$ multiplies the bracket. Both terms disappear, and no learning rate recovers the row.

2. In the softmax gradient, and nowhere else. The row sum is $\sum_j p_j(g_j - p\cdot g) = p\cdot g - (p\cdot g)\sum_j p_j = 0$ for any $g$. Thus a wrong $dP$, a wrong $V$ or a wrong scale cannot cause a sum that is not zero. Those errors would give a wrong answer that still sums to zero.

3. The distribution. The largest entries control a Frobenius norm. Thus a few loud rows keep the average up while other rows return $10^{-13}$. Plot a histogram of the entropy of each row or the gradient norm of each row. A mean cannot show you a failure that affects only a subset.

The habit. Find quantities that must be exactly zero or exactly equal, and assert them. An approximate expectation finds careless code. An exact invariant finds the bug.

Say it backRecommended

Explain this to your favorite LLM, in your own words: an encoder–decoder's encoder has no loss of its own. So how does it learn anything? (This question uses Chapter 09. If you have not read it, come back to this question after it.) Then ask it to correct you. Ask it to question each part where you were vague, not only the parts where you were wrong, because the gaps are in the vague parts.

What a good answer covers — open this afterwards, not before
  1. The loss uses only decoder outputs. The encoder is in the graph only through the memory that it makes.
  2. The only edges out of the memory are the cross-attention key and value projections of each decoder layer.
  3. There is no query term, because cross-attention makes its queries from decoder hidden states. Thus no gradient comes back that way.
  4. Each decoder layer contributes. The contributions add into one tensor before they get to the encoder.
  5. Thus the encoder learns to be useful for lookups. "End-to-end" means that the gradient found a path. It does not mean that anything had direct supervision.

Most common miss. The answer "through backpropagation" only repeats the question. The content is which edges exist. If you cannot say why there is no $W^Q$ term, you have not followed the graph.
